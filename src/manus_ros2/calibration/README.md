Place MANUS glove calibration files here:

- `Calibration_left.mcal`
- `Calibration_right.mcal`

These files are produced by the packaged MANUS calibration GUI:

```bash
cd /home/huangzizhe/Download/Manus_L20_retarget
./deploy/manus-calibration/run.sh
```

`bringup` launch files pass these paths to `manus_ros2/manus_data_publisher` by
default when `start_manus:=true`.

This is the official MANUS glove `.mcal` calibration only. It is separate from
the project-specific L20 retarget YAML calibration generated by
`ros2 run manus_l20_retarget calibration_capture ...`.
